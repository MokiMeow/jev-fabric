# Governance

Jev Fabric is initially maintained by the repository owner, MokiMeow. There is no
foundation, elected council, or guaranteed review/service-level agreement at this stage.

The maintainer decides releases, architecture, and merge readiness after considering
evidence, compatibility, security boundaries, and community feedback. Significant
behavior changes should be discussed in a public issue before implementation when
practical. This document will be updated if maintainership or decision-making changes.

Security vulnerabilities are handled through GitHub private vulnerability reporting,
not public issues; see `SECURITY.md`.
