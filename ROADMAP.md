# Roadmap
This alpha focuses on bounded decisions, offline reproducibility, and host-controlled authority.

- Validate host adapters against installed host releases and publish dated evidence.
- Add reproducible target-domain evaluation datasets supplied by their owners.
- Improve provider cancellation and capability evidence as SDKs evolve.
- Add package publication only after trusted-publishing and release checks are configured.

Roadmap items are intentions, not commitments or compatibility guarantees.
