# Support

Start with [troubleshooting](docs/reference/troubleshooting.md), then open a GitHub issue with a minimal redacted reproduction, Node version, package versions, command, and expected versus actual behavior. Do not put credentials, raw user data, bearer tokens, receipts containing sensitive context, or security vulnerabilities in a public issue.

For vulnerabilities, use the repository’s private security reporting route when it is available; do not disclose them in a public issue.
