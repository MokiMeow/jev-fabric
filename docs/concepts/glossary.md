# Glossary

| Term | Meaning |
| --- | --- |
| Candidate | A host-supplied, bounded option that a provider may select. |
| Decision pack | A trusted definition of projection, candidates, questions, interpretation, and failure behavior. |
| Deterministic preflight | Static policy checks that run before a provider and can deny without inference. |
| Evidence class | A label describing what a committed artifact establishes and its limits. |
| Host | The application or agent integration that owns identity, policy, and any action. |
| Provider | A service that returns typed semantic answers; it has no authority. |
| Receipt | Redacted provenance for a decision, not a permission grant. |
| Semantic proposal | A pack interpretation before trusted policy resolves a final outcome. |
| Ticket | A separate scoped, expiring host-checked action artifact; ordinary receipts do not contain it. |
