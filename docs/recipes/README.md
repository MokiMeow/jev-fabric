# Recipes
These recipes show where bounded semantic decisions help. They are patterns, not permission to automate high-impact actions.

- [Local coding and testing](local-coding.md): route a request or triage test evidence.
- [RAG evidence](rag.md): rank retrieved sources while retaining citations.
- [Browser assistance](browser.md): advise a next step; never execute from model output.
- [Experimental WebMCP](webmcp-browser.md): bind a page-declared tool to trusted origin, frame, schema, policy, and state without executing it.
- [SaaS support](support.md): route a ticket with explicit queues.
- [CI](ci.md): screen bounded failure evidence and escalate uncertainty.
- [Fintech and security](high-impact.md): use screening only behind strict policy and human review.
- [Tool environments](../integrations/tool-environments.md): route among declared browser, DCC, engine, and CAD actions while a native adapter retains authority.
