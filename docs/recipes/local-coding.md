# Local coding and testing
Use `route` to choose a declared work lane, `screen` to triage bounded test output, or `completion` to compare claimed checks with observed checks. Keep file operations, commands, and test execution in a trusted host. A receipt can tell the host why it should ask a reviewer; it cannot approve a code change.

Start with [route-skills](../../examples/route-skills/README.md) and [CI triage](../../examples/ci-triage/README.md).
