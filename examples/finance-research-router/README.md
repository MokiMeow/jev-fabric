# Read-only finance research router

Runs one fully offline, synthetic market-research request. Six independent
answers arrive in one scripted batch and produce a bounded `plot_price`
proposal for an allowlisted symbol and semantic window.

No analytics tool runs. The result explicitly carries no authority and requires
host revalidation. Its negative path proves that an execution-capable boundary
is denied before a provider call. This example is construction evidence, not a
Jev accuracy, latency, or cost result.

Run `pnpm exec tsx examples/finance-research-router/index.ts`.
