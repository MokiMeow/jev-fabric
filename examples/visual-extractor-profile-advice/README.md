# Visual extractor-profile advice

This offline example binds one fixed-vocabulary DCC viewport finding to an
already source-bound visual observation, then advises requesting structured
state. It loads no image and has no browser, Blender, Unreal, Unity, Godot,
FreeCAD, network, command, action, or authorization integration. The profile
only limits evidence vocabulary; it does not establish that the extractor is
correct. The negative path abstains.

Run `pnpm exec tsx examples/visual-extractor-profile-advice/index.ts`.
