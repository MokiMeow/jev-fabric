# FreeCAD contract

Use a small, workbench-owned catalogue of document transactions: for example,
inspect a declared property, apply a validated template, or run a known
recompute/postcondition check. Bind object identity and units to the trusted
adapter. FreeCAD's [source documentation](https://freecad.github.io/SourceDoc/)
and [module reference](https://freecad.github.io/API/modules.html) describe its
C++/Python, document, property, and units surfaces.

Do not expose the Python console, arbitrary macro text, file paths, raw geometry
expressions, or arbitrary workbench commands.
