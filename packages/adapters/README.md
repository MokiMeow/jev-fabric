# @mokimeow/jev-fabric-adapters

Host adapter and integration generators for [Jev Fabric](https://github.com/MokiMeow/jev-fabric).

## Install

`npm install @mokimeow/jev-fabric-adapters`

## Use

Import canonical adapter models and generation/validation helpers from the package root.

Generated host integrations preserve advisory-only semantics and do not grant execution authority.

Read the [repository documentation](https://github.com/MokiMeow/jev-fabric/tree/main/docs), [security boundary](https://github.com/MokiMeow/jev-fabric/tree/main/docs/security), and [Apache-2.0 license](https://github.com/MokiMeow/jev-fabric/blob/main/LICENSE). Requires Node.js >=22.14 and <25.
