# @mokimeow/jev-fabric-cli

Jev Fabric command-line interface for [Jev Fabric](https://github.com/MokiMeow/jev-fabric).

## Install

`npm install @mokimeow/jev-fabric-cli`

## Use

Install the package and run `jev-fabric --help`; see the repository CLI reference for bounded offline commands.

Live provider use requires the CLI `--live` gate, an allowlisted provider, credentials, and declared budgets. The exposed conversation key is never a valid configuration source.

Read the [repository documentation](https://github.com/MokiMeow/jev-fabric/tree/main/docs), [security boundary](https://github.com/MokiMeow/jev-fabric/tree/main/docs/security), and [Apache-2.0 license](https://github.com/MokiMeow/jev-fabric/blob/main/LICENSE). Requires Node.js >=22.14 and <25.
