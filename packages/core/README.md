# @mokimeow/jev-fabric-core

Bounded decision runtime primitives for [Jev Fabric](https://github.com/MokiMeow/jev-fabric).

## Install

`npm install @mokimeow/jev-fabric-core`

## Use

Create a bounded pack and call the runtime with trusted identity, validated state, candidates, and a deadline.

This package returns advisory typed data and receipts; it never authorizes or executes an action.

Read the [repository documentation](https://github.com/MokiMeow/jev-fabric/tree/main/docs), [security boundary](https://github.com/MokiMeow/jev-fabric/tree/main/docs/security), and [Apache-2.0 license](https://github.com/MokiMeow/jev-fabric/blob/main/LICENSE). Requires Node.js >=22.14 and <25.
