# @mokimeow/jev-fabric-evals

Offline evaluation and replay helpers for [Jev Fabric](https://github.com/MokiMeow/jev-fabric).

## Install

`npm install @mokimeow/jev-fabric-evals`

## Use

Import evaluators from the package root and run them against retained, redacted fixtures.

Evaluation is offline by default and does not call a provider.

Read the [repository documentation](https://github.com/MokiMeow/jev-fabric/tree/main/docs), [security boundary](https://github.com/MokiMeow/jev-fabric/tree/main/docs/security), and [Apache-2.0 license](https://github.com/MokiMeow/jev-fabric/blob/main/LICENSE). Requires Node.js >=22.14 and <25.
