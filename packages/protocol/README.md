# @mokimeow/jev-fabric-protocol

Provider-neutral protocol schemas for [Jev Fabric](https://github.com/MokiMeow/jev-fabric).

## Install

`npm install @mokimeow/jev-fabric-protocol`

## Use

Import schemas and types from the package root; validate untrusted provider output before it crosses a trust boundary.

No credentials or network calls are included.

Read the [repository documentation](https://github.com/MokiMeow/jev-fabric/tree/main/docs), [security boundary](https://github.com/MokiMeow/jev-fabric/tree/main/docs/security), and [Apache-2.0 license](https://github.com/MokiMeow/jev-fabric/blob/main/LICENSE). Requires Node.js >=22.14 and <25.
