# @mokimeow/jev-fabric-provider-openai-compatible

OpenAI-compatible advisory provider adapter for [Jev Fabric](https://github.com/MokiMeow/jev-fabric).

## Install

`npm install @mokimeow/jev-fabric-provider-openai-compatible`

## Use

Import the adapter from the package root and configure an allowlisted HTTPS endpoint through the bounded runtime.

Provider responses remain advisory data; endpoint and credential policy stays with the host.

Read the [repository documentation](https://github.com/MokiMeow/jev-fabric/tree/main/docs), [security boundary](https://github.com/MokiMeow/jev-fabric/tree/main/docs/security), and [Apache-2.0 license](https://github.com/MokiMeow/jev-fabric/blob/main/LICENSE). Requires Node.js >=22.14 and <25.
