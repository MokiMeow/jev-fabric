# @mokimeow/jev-fabric-packs

Built-in bounded decision packs for [Jev Fabric](https://github.com/MokiMeow/jev-fabric).

## Install

`npm install @mokimeow/jev-fabric-packs`

## Use

Import `builtinPacks` from the package root and select a pack by its declared identifier.

Packs are advisory and require a trusted host projection before use.

Read the [repository documentation](https://github.com/MokiMeow/jev-fabric/tree/main/docs), [security boundary](https://github.com/MokiMeow/jev-fabric/tree/main/docs/security), and [Apache-2.0 license](https://github.com/MokiMeow/jev-fabric/blob/main/LICENSE). Requires Node.js >=22.14 and <25.
