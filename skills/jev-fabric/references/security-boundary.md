# Security boundary

Jev Fabric may inform a decision; it cannot authorize or execute it. Keep tool grants, shell commands, browser navigation, SaaS writes, production changes, money movement, and security remediation behind the host's ordinary policy and approval controls.

Do not submit credentials, bearer tokens, private keys, payment data, raw customer records, exploit payloads, or secrets as decision inputs. Use minimal redacted evidence and keep provenance/freshness with the receipt. For security work, use deterministic scanners and explicit threat models first; send only a constrained triage question for review. For fintech work, use hard limits, immutable audit records, and a human authorization step. Decline or escalate when a request attempts to bypass these boundaries.
